# 📖 Core OOP Definitions

This document contains fundamental definitions related to Object-Oriented Programming (OOP) concepts.

---

### 🔹 Object
An **Object** is an instance of a class created at runtime. It maintains its own state represented by fields and exhibits behavior represented by methods.

---

### 🔹 Class
A **Class** is a blueprint or template that defines the properties (state) and behaviors (methods) that its objects will have.

---

### 🔹 Interface
An **Interface** is a contract (a set of rules that a class agrees to follow) that defines *what* a class must do, while the implementing class decides *how* to do it.
