# 🦎 Polymorphism

> - Performing a single action in different ways ("many forms").
> - Allowing a single interface, method, or reference to represent different underlying behaviors.

---

## 📌 Definition

**Polymorphism** is an OOP principle where a single interface, method, or reference can represent and perform different behaviors depending on the object or context.

---

## 🔑 Key Concepts

- **Compile-Time Polymorphism (Static / Early Binding):** Resolved at compile time, achieved through method overloading and operator overloading.
- **Runtime Polymorphism (Dynamic / Late Binding):** Resolved at runtime, achieved through method overriding where a child class provides a specific implementation of a parent class or interface method.
- **Flexibility & Extensibility:** Allows writing generic, decoupled code that works with a shared abstraction while automatically executing subtype-specific behavior.
