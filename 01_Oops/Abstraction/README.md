# 🎭 Abstraction

> - Exposing only what is necessary and hiding the underlying complexity.
> - Hiding the implementation only, not the data.

---

## 📌 Definition

**Abstraction** means exposing only the essential information or operations that a user needs, while hiding the unnecessary internal implementation details.

---

## 🔑 Key Concepts

- **What is exposed:** Essential features, contracts, and operations that callers need to interact with.
- **What is hidden:** Internal state, complex algorithms, and underlying implementation mechanics.
