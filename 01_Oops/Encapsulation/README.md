# 💊 Encapsulation

> - Bundling data and methods into a single unit.
> - Hiding the internal data and controlling how it is accessed or modified.

---

## 📌 Definition

**Encapsulation** is the OOP principle of bundling data and the methods that operate on that data into a single unit (class), while restricting direct access to the internal data and controlling how it is accessed or modified.

---

## 🔑 Key Concepts

- **Bundling (Data + Methods):** Grouping related state (fields) and behavior (methods) together inside a class.
- **Data Hiding & Access Control:** Restricting direct access to internal variables and exposing safe, controlled ways to interact with them.
