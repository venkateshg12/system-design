# 🧬 Inheritance

> - Acquiring properties and behaviors from an existing class.
> - Promoting code reusability and establishing an IS-A relationship.

---

## 📌 Definition

**Inheritance** is an OOP mechanism in which a child class acquires the properties and behaviors of an existing parent class and can add its own specialized properties and behaviors, promoting code reusability.

---

## 🔑 Key Concepts

- **Code Reusability:** Child classes inherit fields and methods from the parent class, avoiding duplicate code.
- **IS-A Relationship:** Models a hierarchical relationship where the child class is a specialized type of the parent class (e.g., `Developer` IS-A `Employee`).
- **Specialization & Extension:** Child classes can define additional characteristics/behaviors or override inherited ones to meet specific needs.
